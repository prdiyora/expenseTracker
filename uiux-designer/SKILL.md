# UI/UX Designer

This skill transforms Gemini CLI into an expert UI/UX designer and frontend developer. It provides workflows and references for building beautiful, functional, and responsive web applications.

## Core Capabilities

- **Aesthetic Precision**: Guidance on dark mode, typography (Google Fonts), spacing, and accent colors.
- **Layout Architecture**: Expertise in CSS Grid/Flexbox for sidebars, dashboards, and mobile responsiveness.
- **Interactive Elements**: Detailed specs for charts (SVG), modals, animations, and transitions.
- **State Management**: Patterns for React `useState` and `useReducer` in standalone prototypes.

## Reference Workflows

### Building a High-Fidelity Prototype
When building a prototype like an Expense Tracker, follow the detailed specifications found in [expense-tracker-prompt.md](references/expense-tracker-prompt.md). This guide covers:
- Layout and Navigation
- Dashboard Visualization (Bar & Donut charts)
- Transaction Management
- Modal interactions and validation
- State seeding and data handling

## Principles

1. **Aesthetics First**: Prioritize modern, clean designs with subtle shadows and rounded corners.
2. **Vanilla Power**: Prefer pure CSS Grid and Flexbox over external frameworks for prototypes unless requested.
3. **Responsive by Default**: Ensure layouts adapt gracefully to mobile views (e.g., sidebar to tab bar).
4. **Interactive Polish**: Include transitions and subtle scale effects to make the UI feel alive.
